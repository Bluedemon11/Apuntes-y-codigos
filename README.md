## 📦 ETAPA 1: Fundamentos y Operación Local (Semanas 1 a 4)

**Objetivo:** Dominar el funcionamiento interno de una computadora, una red local y la lógica básica de programación.

### 📅 Cronograma de la Etapa 1

| Semana | 🌐 Redes | 🐧 Linux | 🐍 Python | 🛡️ Ciberseguridad |
| :--- | :--- | :--- | :--- | :--- |
| **Semana 1** *(En curso)* | Direccionamiento IPv4 básico | Estructura de directorios | Variables y bucles | Tríada CIA y modelos de ataque |
| **Semana 2** | Modelo OSI (Capas 2-4), MAC y ARP | Permisos lógicos (chmod octal) | Funciones y archivos de texto | Cifrado en tránsito (TLS/SSH) |
| **Semana 3** | Enrutamiento dinámico (OSPF básico) | Monitoreo de hardware (`df`, `free`) | Librerías del sistema (`os`, `sys`) | Anatomía de malware |
| **Semana 4** | Listas de Control de Acceso (ACLs Cisco) | Editor Vi/Vim a fondo | Expresiones regulares (Regex) | Gestión de vulnerabilidades (CVE/CVSS) |

---

## 📦 ETAPA 2: Infraestructura Avanzada y Scripting de Sistema (Semanas 5 a 8)

**Objetivo:** Aprender a conectar sistemas, entender IPv6 y crear scripts automatizados que auditen el sistema.

### 📅 Cronograma de la Etapa 2

| Semana | 🌐 Redes | 🐧 Linux | 🐍 Python | 🛡️ Ciberseguridad |
| :--- | :--- | :--- | :--- | :--- |
| **Semana 5** | Direccionamiento IPv6 (Estructura y tipos) | Almacenamiento avanzado (Particiones/FS) | Scripting de administración | Análisis de configuraciones |
| **Semana 6** | Redes Virtuales (VLANs) y Troncales (802.1Q) | Gestión de logs (`/var/log/syslog`) | Filtro de alertas de logs en tiempo real | Detección de anomalías |
| **Semana 7** | Protocolos esenciales (DHCP, DNS, NAT) | Automatización de tareas de sistema | Pings automatizados a múltiples dispositivos | Auditoría de conectividad |
| **Semana 8** | Conmutación Avanzada (EtherChannel/Port-Security) | Endurecimiento básico del sistema | **Proyecto:** Escáner de puertos personalizado | Escaneo y reconocimiento (Estilo Nmap) |

---

## 📦 ETAPA 3: Redes Empresariales, Automatización y SecOps (Semanas 9 a 12+)

**Objetivo:** Integrar todo el conocimiento. Programar scripts que configuren redes de forma remota, analizar tráfico real y responder a escenarios del mundo profesional.

### 📅 Cronograma de la Etapa 3

| Semana | 🌐 Redes & Infraestructura | 🐧 Linux & Operaciones | 🐍 Python & Automatización |
| :--- | :--- | :--- | :--- |
| **Semana 9** | Enrutamiento inter-VLAN (Router-on-a-Stick) | Endurecimiento de SSH (Llaves SSH) | Manejo de peticiones web (Librería `requests`) |
| **Semana 10** | Arquitectura de Redes Inalámbricas (WLANs) | Análisis de tráfico de red | Uso de Wireshark para captura y análisis |
| **Semana 11** | Automatización a gran escala (SDN, APIs, JSON/XML) | Integración de scripts con sistemas | Librerías especializadas en redes (`Netmiko`) |
| **Semana 12** *(Cierre)* | **🚀 Proyecto Integrador Final:** | Script maestro de automatización | Recolección de configs, SecOps y reporte CVE |
